## 検証

Node 22.23.3、既存Chromiumで実行した。直前の関連検証は [自然な動き](natural-motion-verification.ja.md)、[母音口パク](vowel-lipsync-verification.ja.md)、[公式更新](upstream-update.ja.md) を参照。

- `npm run lint`、`npm run build`: 成功。
- 全単体テスト: **101成功・4失敗（105件）**。3件はWindows symlink作成EPERM、1件はサンプルコピーのHTTP500。コピーの処理は既存ブランチHEAD `c82d7c3` と文字列比較で同一と確認した。全体PASSとは扱わない。
- 数値変形: 14姿勢・68,397点、最大差 **0px**。スプライト10層も **0px**。物理差 `5.684341886080802e-14px`。
- Pythonレイヤー生成6件・エージェントツール6件: 成功。uvのoffline/no-projectモードでキャッシュを使用、新規取得なし。
- 全E2E: **62成功・10失敗（72件、12.2分）**。公式配信9件、自然な動き4件、母音判別2件、既存配信2件、新規統合1件は成功した。
- 10失敗のうち `rebuild-guidance` の未一致フォルダー案内は単独再実行で **1件成功**。全体実行の失敗を消して報告せず、断続的失敗として記録する。
- 残る9件は前回の全体実行でも失敗したエディター領域: 新規フォルダーの基準、整数形状の実再構築、角度スイープ、サンプルコピー、フォルダー再開、実レイヤー再構築、素材取り込み、口のフォールバック案内、外部スプライト更新。同じ原因とは断定しない。今回の範囲で未解消。
- 公式README画像16枚は取得済み公式スナップショットとハッシュ一致。ユーザー画像ではない。
- コミット `494e134` に106ファイルの機能・公式更新を記録。本人画像の除外対象パスはステージ0件。
- 自身のmain履歴をマージした `35b8463` は、第1親からのファイル差分なし。検証中のソース状態を変えていないため、上記の検証結果を適用できる。

実カメラ・OBSで使用できることはユーザー報告として確認済み。録画・母音の実会話精度を確認済みとは扱わない。

Issue #2は本人の会話での母音精度・遅延測定が未完了のため、自動で閉じない。
