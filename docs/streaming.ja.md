# OBSで配信する

## 配信画面を選ぶ

公式アップデートのカメラ追跡は、エディターの **配信** から開きます。直接開く場合は `/live.html?project=midonon-sd` です。カメラを開始して正面の顔を校正し、画面内のOBS表示URLを使います。表示用は `/stream.html?project=midonon-sd` で、透明・緑・青などの背景を選べます。顔の向きと口を追跡し、音量によるマイク口パクも併用できます。映像・音声はローカルで処理します。

### 自動瞬き・呼吸・体の揺れ

これらはOBSではなく、**配信** 画面の **自然な動き** で設定します。既定は自動瞬き・正面視線・弱めの呼吸と揺れです。カメラを使わなくても動きます。

- **瞬き** は自動またはカメラ追跡。自動時は少し不規則な間隔で両目を閉じ、頻度を調整できます。
- **視線** は正面またはカメラ追跡。瞬きとは独立して選べます。自動瞬き中も顔の向き・眉・口の追跡は継続します。
- **呼吸の強さ** と **1分あたりの呼吸** で上下動を調整します。強さ0で呼吸の変形を停止します。
- **体の揺れ** は追跡や既存の体の動きに小さな揺れを加えます。0は追加の揺れなしで、既存の体の動きは残ります。
- 設定はアバターごとに同じブラウザー・ホスト・ポートのサイトデータへ保存されます。保存が制限されても現在の画面では使えます。**自然な動きを初期化** で既定に戻せます。

OBSには完成した姿勢を送ります。カメラ・マイク停止中も操作画面とローカルサーバーを開いておき、同じアバターを複数の操作画面で同時に制御しないでください。操作画面を閉じると表示画面は既存の待機動作へ戻ります。背景タブでも更新しますが、PCのスリープやブラウザーのページ凍結中の継続は保証しません。

追加先は公式の配信画面です。以下の母音判別専用画面の **自然な動き** スイッチは従来の動作を保っています。比較調査は [英語の調査資料](research/natural-motion-research.en.md)、Claude Code Opusが策定した仕様は [英語仕様](natural-motion-spec.en.md) に記録しています。

以下の手順は、既存の **母音口パク** ボタンから開く `/stream` のマイク母音判別用です。校正した「あいうえお」の判別はこちらを使います。公式のカメラ画面と母音判別画面は別の操作・表示経路なので、OBSには利用する操作画面が案内するURLを指定してください。

## 起動と表示

1. リポジトリで `npm run dev` を実行し、端末に表示されたローカルURLをブラウザーで開きます。
2. エディターで使いたいプロジェクトを選び、上部の **母音口パク**（英語UIでは **Vowel lip sync**）を開きます。URL末尾を `/stream` にして直接開くこともできます。
3. 配信コントローラーでアバターを選び、**マイクを開始** を押してブラウザーのマイク使用を許可します。
4. **OBSへ追加** のURLをコピーします。OBSのソースから **ブラウザー** を追加し、「ローカルファイル」はオフにしてURLを貼ります。まず幅1080・高さ1080・FPS30で確認してください。
5. 背景は透明なので、ゲームやカメラの映像より上のソースとして配置し、位置と大きさを調整します。OBSの「対話」でマイク許可をする必要はありません。

操作画面は通常のChromeまたはEdgeで開きます。OBSには `/stream/overlay?project=…` の表示用URLを指定してください。ホスト名とポートはコピーしたものをそのまま使います。サーバーと操作画面は配信中も開いておきます。同じアバターの操作画面は1つだけ使ってください。

## マイク口パク

未校正では、マイクの音量に応じて「あ」の口形が開き、無音で閉じます。校正後は声の共鳴周波数から「あ・い・う・え・お」の口形を推定できます。生成AI・学習済みモデル・文字起こしは使いません。音声は録音・再生・外部送信せず、音量と推定した母音だけをローカルサーバーへ渡します。

OBSでは、普段どおり **音声入力キャプチャ** または設定のマイク入力を用意してください。アバターのブラウザーソースから声は出ません。マイクのモニター再生はこのアプリにはありません。

- 普通に話しても口が開かない場合：**感度** を上げます。
- 無言でも口が動く場合：**無音しきい値** を上げます。
- マイクを変える場合：入力デバイスを選んで **マイクを開始** を押します。デバイス名はマイクを一度許可した後に表示されます。
- マイクを停止・切断した場合や操作画面からの更新が途絶えた場合：口は閉じます。接続断の失効時間は約1.5秒です。
- 許可拒否の場合：ブラウザーのサイト設定でマイクを許可して再試行します。

操作画面を閉じたり、PCをスリープさせたりすると口パクは動きません。背景タブや最小化で更新が遅くなる場合は、操作画面を別ウインドウで表示しておいてください。

## あいうえおの校正

1. 普段の配信で使うマイクを開始します。無言で口が閉じ、普通の声で開くように感度・無音しきい値を調整します。
2. **校正を開始** を押すと最初の「あ」の測定が始まります。「あー」と普段の声で約2秒、一定に発声してください。大声や特別に高い声にする必要はありません。
3. 測定が終わったら、表示された次の測定ボタンを押して発声します。「あ・あ・い・い・う・う・え・え・お・お」の計10回です。各測定は準備ができてから開始できます。
4. 安定した声が不足した場合は、同じ測定をやり直します。2回の声が一致しない場合や、母音同士が近すぎる場合は、校正を最初からやり直してください。
5. 完了すると **母音判別を使う** がオンになります。オフにすれば、いつでも音量だけの口パクへ戻せます。

校正の数値は、このブラウザーのサイトデータ（localStorage）へ、実際の入力デバイスと解析上限ごとに保存します。生音声は保存しません。同じブラウザー・ホスト名・ポートでマイクを開始すると対応する保存値を読み込みます。保存できないブラウザーでは、現在の画面を開いている間だけ使えます。**校正を削除** で現在のマイク・解析上限の保存値を消せます。すべての保存値を消す場合は、このローカルサイトのブラウザーデータを削除してください。

マイクを替えたり、ボイスチェンジャーや音声処理を変えたり、普段と違う声を使うときは再校正してください。校正中と使用中で、ブラウザーへの入力音を同じ条件にします。ブラウザーへはエコー除去・ノイズ抑制オン、自動音量調整オフを要求しますが、実際の処理はブラウザーやデバイスによって異なります。

**解析上限** は最初は5500Hzを試してください。母音が区別できない場合はマイクを停止し、4500〜6500Hzの別の上限を選んで、マイクを開始して校正し直します。変更前の校正値は別の上限へ流用しません。声の高さだけで適切な値が決まるわけではありません。

判定結果とF1/F2を画面に表示します。新しい母音は約30ms続いてから切り替えます。判別が曖昧なときは直前の口形を最大120ms保持し、その後は音量だけの口パクへ戻ります。無音では口を閉じます。解析結果が途絶えた場合はマイクを停止して再起動を案内します。

これは音声からの推定です。子音、ささやき、笑い声、高い声、雑音では判別できなかったり誤判定したりします。持続母音で校正できても、普通の会話で同じ精度になるとは限りません。発話していないときの実際の口形は推定しません。「え」は半開きの「あ」の絵、「う」は幅を狭めた「お」の絵を使うため、判定上の5種類がすべて専用画像というわけではありません。

### 本人の声とOBSでの確認

校正後、別の発声で各母音を10回ずつ試し、正しい判定・誤判定・判別不能を分けて数えます。普通の会話でも、口形のちらつきや長い「あ」への復帰がないか確認してください。笑い声・ささやき・無言・背景雑音、マイクの停止・抜き差しも確認します。録音する場合は自分でローカルに保存し、GitHubへ添付しないでください。

OBSでは短い録画を使って、声から口形が変わるまでの遅延を確認します。ブラウザーの表示連携は約33ms間隔、描画は最大30FPSですが、解析・平滑化・HTTP通信・OBS側の描画を含む総遅延を保証する値ではありません。自動テストは合成した声とブラウザーの音声経路を確認するもので、本人の会話の精度・実機マイク・OBS録画は別途確認が必要です。

## 表情キー

| キー | 表情 |
|---|---|
| 1 | 通常 |
| 2 | 笑顔 |
| 3 | 半閉眼 |
| 4 | ウインク |
| 5 | 驚き |

ボタンでも切り替えられます。キーは操作画面にフォーカスがあるときだけ有効です。入力欄・選択欄の操作中は反応しません。ゲーム操作中に使うグローバルホットキーは未実装です。カメラによる顔トラッキングは、冒頭の公式カメラ画面を使ってください。

**自然な動き** をオフにすると首・視線・瞬き・呼吸を固定します。表情と口パクは引き続き操作できます。髪は動いた後の揺れが収まるまで動きます。

## 制限と確認方法

この配信機能は `npm run dev` のローカルサーバーで使います。`dist/` を静的ホスティングしただけではプロジェクト読込・操作連携は動きません。サーバーを再起動すると操作状態は初期化されます。

表示用画面はアバター以外のUIを描画しません。表示されない場合は操作画面の読み込み状態と端末のエラーを確認し、URLのプロジェクト名が一致していることを確認してください。起動時にポートが変わったらOBSのURLもコピーし直します。

配信前にOBSで短い録画を行い、背景の透過、マイク音声、口パクのタイミングを確認してください。このリポジトリの自動テストは擬似マイクと別ブラウザー環境で連携を確認します。実機のマイクとOBS本体での録画は別途確認が必要です。
