# 手動表情と漫画的な目

`/live.html?project=midonon-sd` の「表情」で選択します。選んだ表情は解除・変更するまで維持され、OBSの `/stream.html` にも同じ数値が送られます。開いている操作画面とOBSのブラウザーソースを再読み込みしてください。

| キー | 表情 |
| --- | --- |
| 1 | 通常 |
| 2 | 笑顔 |
| 3 | 半目 |
| 4 | ウインク |
| 5 | 驚き |
| 6 | ぐるぐる目 |
| 7 | バッテン目 |

同じ表情をもう一度選ぶと通常へ戻ります。キーは操作画面にフォーカスがある間だけ有効で、ゲームやOBSへフォーカスを移しても選択中の表情は維持されます。入力欄・IME変換中・キーリピートでは切り替えません。「キーを変更」で割当を変更でき、割当だけをプロジェクト別に保存します。再読込時の表情は通常です。

## 動きと素材

180msで切り替わります。口パク、頭と体の動き、呼吸は継続します。半目は瞬きに従い、ウインクの閉じた目は閉じたままです。特殊な目では通常の目・瞬き画像を隠し、解除したときに現在の通常の目へ戻ります。自動で表情を選ぶ処理はありません。

ぐるぐる目・バッテン目は任意の素材です。両目の画像と、元の目を不透明に覆う肌色のパッチが必要です。素材がない、壊れている、片目しかない、元の目が透ける場合は、その表情を無効にして理由を表示します。従来のプロジェクトはそのまま動作します。

既存の構築済みプロジェクトで、ローカルのベクター描画から素材を作るには次を使います。元の画像・リグを変更せず、`variants/eyes_spiral.png` と `eyes_cross.png` を作成します。生成AIや外部サービスは呼びません。

```powershell
npm run validate-rig -- projects/<name>/rig.draft.json
uv run tools/create-cartoon-eyes.py projects/<name>
uv run tools/build-sprites.py projects/<name> --tolerance 0
```

`midonon-sd` にはローカルで素材を構築済みです。目だけを差し替え、参考画像にある汗、外側の渦、ポーズ、口の表情は追加していません。素材・参考画像・確認画像はignored `projects/` 内にだけ置き、GitHubへ送っていません。
