# 自然な動きの実装・確認

2026-10-06。公開公式資料の比較調査を英語にまとめ、実際のClaude Code Opusに仕様策定を依頼し、主担当が実装した。

## 調査と仕様策定

- [英語調査](research/natural-motion-research.en.md): VTube Studio、Warudo、VSeeFace、Live2D Cubismの公式資料。パラメーターごとの制御権、自動瞬き、独立した呼吸・体の揺れ、なめらかな切り替えを採用した。競合ソフトのインストールや実機比較は行っていない。
- [英語の委譲内容](research/natural-motion-opus-brief.en.md)、[訂正依頼](research/natural-motion-opus-correction.en.md)、[Opusの修正版仕様](natural-motion-spec.en.md)。
- Claude Code 2.1.290、`--model opus --effort medium`。応答メタデータは `claude-opus-5-5`。初回153,052ms、訂正129,727ms、各1ターン、エラーなし。
- 調査と必要最小の構造説明だけを英語で渡した。画像・音声・秘密情報・ローカル識別パス・ソース全文は送っていない。ツール無効・セッション保存無効の仕様策定。
- 初稿の複数回の `setParameters` 呼び出しは既存APIの全体置換と衝突するため、コード照合後に訂正を依頼した。修正版を主担当が再確認した。

## 実装範囲

- `src/engine/parameter-overrides.ts`、`createMeshAvatar.js`、`index.ts`: 追跡・口パク後の独立した上書き段階。現在フレームへの置換・加算・重みと範囲制限。空の設定では既存値を変えない。描画とパラメーターだけの更新で同じ経路を使用する。
- `src/live/natural-motion.ts`: 秒単位の瞬き・呼吸・揺れ。閉じ切りの保持、長い停止後の瞬き再生防止、切り替えと強さの平滑化。乱数注入で再現可能。顔・口・眉・表情のキーは生成しない。
- `src/live/natural-settings.ts`、`NaturalMotionControls.tsx`、`LiveApp.tsx`: 自動/追跡の瞬き、正面/追跡の視線、瞬き頻度、呼吸の強さと周期、追加の体の揺れ、初期化。日本語・英語・中国語。プロジェクト単位のバージョン付きlocalStorage、300msの保存待ち、不正値の回復と保存拒否時の継続。
- OBSへは完成した数値姿勢を継続送信する。呼吸0でも操作画面の設定を維持するため、仕様の条件付き送信から常時送信へ調整した。
- [利用手順](streaming.ja.md)。追加先は公式 `/live.html`。既存の `/stream` の母音判別経路と操作は維持した。依存追加なし。

## 未確認・制限

- 実機カメラとOBSでの使用は上記のユーザー確認済み。本人の自然な発話での母音判別精度、OBS録画と総遅延、頻度や振幅の好みに合わせた最終調整は、この報告では確認範囲に含めていない。
- 非表示テストはvisibilityStateとRAF停止の模擬。OSのスリープやブラウザーの完全なページ凍結中の動作を保証しない。
- 同じアバターの複数操作画面は未対応。操作画面を閉じると表示側は従来の待機動作へ戻る。
- 全E2Eは今回は再実行していない。前回の公式取り込み時に残ったエディター領域の失敗は解決済みとは扱わない。Pythonツールは変更しておらず、前回の各6件成功の確認を再利用した。
- 実装時点ではコミット・push・PR更新を行っていなかった。ユーザーの区切りの依頼により統合する。統合前検証と最終状態は [統合記録](integration-verification.ja.md) を参照。
